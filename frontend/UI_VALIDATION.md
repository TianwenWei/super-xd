# Demo界面验收方法

界面连接本地Demo，推理经生产NLPService；通过模拟器不表示真实车端已集成。每批记录代码/模型版本、浏览器、窗口尺寸、配置及是否真实模型/音频；截图、导出JSON和完整trace放在忽略的 `data/validation/`，不提交Git。

## 自动检查

```sh
cd frontend
node --test tests/*.test.mjs
npm run build
```

隔离媒体/网络测试不替代实体麦克风、AEC、扬声器或浏览器真实播放。

## 浏览器核验

桌面与约400px窄屏分别核对：对话、车况与任务可访问，输入不被长内容挤出，文本/JSON可滚动且无页面横向溢出。功能调用与计划显示在正确轮次，只有真实回执才显示执行成功；unknown、失败、取消和未开始动作明确区分。

验证同轮组合动作、咨询无动作、音区切换与冻结、环境地点/日期、后台登记/进度/澄清/修订/取消，以及最新revision结果。重连恢复当前会话快照、function calls、计划账本和任务；服务端会话失效明确提示，不伪装跨重启恢复。

轨迹抽屉按会话/轮次/任务筛选、分页增量、展开和复制完整JSON；实际模型原文与模板/最终回复区分。打开长记录时新事件不得强制跳位置或收起内容。生成回答与实际audio.text可逐条对照，后台全文与简短播报都可查看。

语音核对权限/解锁失败、连续监听、VAD停播、final提交、新输入打断、迟到PCM隔离、audio.ended后自然drain、播放反馈和任务等候。手动暂停不能被迟到恢复覆盖；媒体/导航各动作要核对独立设备状态及版本回执。

音频口径见[音频验收](../docs/AUDIO_VALIDATION.md)，接口见[Demo接口](../docs/INTERFACES.md)，总体方法见[验收方法](../docs/VALIDATION.md)。本文件不声明当前浏览器或真实音频已通过。
