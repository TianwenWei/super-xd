# 浏览器端到端 PCM 音频验收

2026-10-11，本机连续在线原型，真实 Ark Talker / Thinker、Tavily 与火山 Speech 小何2.0。当前核心目标为**每次浏览器提交 query 到收到首个真实非零 PCM ≤2000ms**，且保持动作语义正确。任一次超标、错误或缺音频都不满足“每次”目标；P50 达标不能代替全部请求达标。文字首字、车控回执和供应商首包是诊断指标，旧批次不作为本轮音频成功证据。

**最终未达标。** 15次代表性请求全部正常播完，但仅3/15（20%）在2秒内收到首非零PCM；连同2次刻意取消/仲裁验证的完整17次提交，比例为3/17（17.6%）。增量PCM链路与取消/播放仲裁已经真实验证，不能因此宣称满足每请求2秒要求。

## 测量与分母

通过真实 Chrome 页面表单提交，不由服务端脚本代替浏览器接收音频。启用朗读的用户手势创建并解锁 AudioContext，随后每次 query 生成 client_request_id，以页面 performance.now 记录 submit_perf_ms。独立音频连接的 audio.started 通过 request / turn / playback 三个 ID 关联；合法 PCM 中首次接收到非零 int16 样本时记录 first_nonzero_pcm_perf_ms，两者相减为核心耗时。供应商/模型/服务端时钟不替代浏览器时钟。

界面的“音频测量 / 复制测量 JSON”保留每个已提交请求，包括还未收到 audio.started 的 pending 记录、取消、错误及超标；没有因失败而重试替换样本。后台主动回流没有 query 提交时间，独立保留，不混入 query 分母。刻意打断的功能回归单独留存；若它出现在某次测量导出内，仍作为该文件的失败提交保留，聚合器不会自动剔除。

报告分别列出首个 PCM、首个非零 PCM、向 Worklet 入队、Worklet 首次真实/非零样本渲染通知。入队不是开播，Worklet 主线程观测包含线程通知延迟，不是扬声器声学起点。静音补零、元数据、空包、缓存或占位声音不计有效首音频；本版无音频缓存/替代声音。[Web Audio 规范](https://www.w3.org/TR/webaudio/)。

P50/P95 使用实际有效观测值，报告明确标为 observed-only；≤2秒比例以全部提交为分母，另核对正常完成与语义证据。车控必须具有同轮实际执行成功回执、目标状态，并在声音前观察到回执；委托必须真实登记任务后接手；闲聊不能擅自车控/委托。后台负载样本保存提交时至少两个真实 queued/running 任务的快照。

最终采样为问候、闲聊、温度、左前窗、导航、后台任务接手、后台负载车控各两次，共14次，再追加后台负载闲聊1次，构成15次代表子集。另2次专门验证取消/仲裁，全部纳入17次总分母。只将最终服务重启后的首条 query 标为 first-query-after-restart，其余是同页 warm / 累积历史。连接预热/复用诊断同时保留，不能将首 query 称为已证明的冷模型、冷 TLS 或冷供应商测试。

## 超标阶段证据与优化边界

[audio-stage-smoke.json](audio-stage-smoke.json)关联真实模型轨迹和上述浏览器记录。2259.3ms 的秋天闲聊中，模型首 delta 1486.4ms、完整消息1732.1ms；等待完整无工具决策约多245.7ms。服务端1734.9ms才把聊天文字送 TTS，Speech 首文本→首音频521.1ms，服务端首非零PCM2256.3ms，浏览器2259.3ms。各独立时钟只按其本来范围展示，约3ms的末段差值为诊断估计，不能当跨进程精密同步。

当时连接已复用，connection_ready约0ms、供应商session握手232.6ms与模型生成重叠；继续消除连接握手无法单独覆盖该次超标。模型 usage 实际为 null，服务商缓存命中未知，不能声称前缀缓存已经命中或由缓存造成加速。

当前 PCM 接收、传输与 AudioWorklet 播放均增量进行，供应商专项在输入仍开放时即收到首帧；[真实适配器记录](tts-ws-live.json)。当前聊天文字仍等完整模型消息才进入 TTS，工具生成的前缀丢弃，仅真实回执/任务登记后的模板进入合成。这样避免同一消息先生成“已完成”再调用工具时提前播报成功；没有宣称完整 LLM→TTS 文字流式管线。官方双向协议支持持续送入文本和顺序复用会话，当前实现遵循其连接/会话边界。[官方 V3 双向文档](https://docs.volcengine.com/docs/DoubaoVoice/WebSocketBidirectionalStreaming-V3?lang=zh)。
