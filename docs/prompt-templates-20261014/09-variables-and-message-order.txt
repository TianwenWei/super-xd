这些是模板的变量和消息排列说明，不是另一段模型指令。

模板变量

{{skill_index}}：Talker 使用的固定车控子系统索引，来自 catalog。
{{skill_guide}}：Thinker 使用的固定技能索引，来自 catalog。
{{persona_json}}：当前人设配置，仅影响表达。包含 id、name、tone、sentence_length、catchphrase_frequency、voice。
{{task_read_rejections}}：本轮缺少任务读取证据的回答已被拒绝的次数。
{{session_snapshot_json}}：车况、后台任务摘要、recent_places、current_utc、timezone、capabilities，及按条件附加的检查数据。

以下动态数据按各自消息角色传入，不混进固定 system 指令：
用户原句；有角色的历史消息；模型产生的 tool_calls；对应 tool_call_id 的真实工具回执。
工具定义及参数 schema 通过独立的 tools 字段传入。

从旧检查点恢复且有新条件时，另加 user 数据：revision、additional_conditions，以及原固定说明“在已有资料上继续；核对新条件是否需要补查，旧结果不自动证明新条件。”

其他
